# Zomato-Landing-Page – Frontend UI Clone

This project is a fully responsive Zomato landing page clone created using HTML, CSS, and Font Awesome icons. It is designed to closely imitate Zomato’s home UI while maintaining clean structure, reusable components, and responsiveness across different screen sizes.

🚀 Features
⭐ 1. Hero Section

Beautiful full-width background image

Zomato logo

Tagline

Location & search input fields

Fully responsive

⭐ 2. Services Section (What Zomato Offers)

Interactive hover-scaling cards

High-quality images

Clean layout with subtle shadows

⭐ 3. Collections Section

Curated cards with gradient overlays

Modern grid layout

Image-based categories like Luxury Dining, Cafes, Nightlife, etc.

⭐ 4. Get The App Section

Promo banner

Radio selection (Email / Phone)

App link sharing input

Play Store & App Store badges

⭐ 5. Explore Options

Dropdown-style buttons to explore cuisines, restaurant types, cities, etc.

⭐ 6. Footer

Multi-column navigation

Country switcher & language selector

Social media icons

Legal disclaimer

📱 Responsiveness

The website is fully responsive using CSS media queries:

Navigation adapts to screen width

Cards adjust layout in grid

Input containers stack on smaller devices

Footer rearranges into fewer columns

🛠️ Tech Stack

CSS3

Font Awesome

Google Fonts (Poppins)
